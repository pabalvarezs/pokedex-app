# Pokédex

Full-stack Pokédex: React + Vite + TypeScript + Tailwind frontend, Express + TypeScript backend, PostgreSQL 16 + Prisma, Docker Compose.

## Run
```bash
docker compose up --build
```
- Frontend: http://localhost:5173
- Backend API: http://localhost:5000
- Postgres: localhost:5432

## Stack
- Frontend: React, TypeScript, Tailwind CSS, TanStack Query, React Router v6, Axios
- Backend: Node.js, Express, TypeScript, Prisma, Axios (PokéAPI proxy)
- Database: PostgreSQL 16
